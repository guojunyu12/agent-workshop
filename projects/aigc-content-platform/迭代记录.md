## 2026-11-14 · V6 · 模型路由

- 后台模型配置新增“适用模块”和“优先级”。适用模块留空表示三个图片模块全部可用，也可以限定为表情包、手机壁纸或电脑壁纸。
- 用户端切换模块时重新加载可用生图模型，按优先级排序；生图接口再次校验模型模块范围，避免绕过前端误用模型。
- 新增数据库迁移字段 `models.module_scope` 和 `models.priority`，兼容已有数据库。
- 验证：skeleton 测试 40 项通过，仓库测试 578 项通过、88 个子测试通过；本地服务已重启并通过 `/api/health` 与模块模型接口检查。

## 2026-11-14 · V6 · 模型容错

- 模型配置新增备用模型、超时（5–600 秒）和重试次数（0–3 次）。
- 真实生图失败后按配置重试，再切换到备用生图模型；备用模型继续校验启用状态和模块绑定。
- 失败尝试写入用量台账但不扣积分，成功任务只扣一次积分；回执记录请求模型、实际模型和尝试明细。
- 验证：skeleton 测试 42 项通过。

- 新建 `prd/V6.md`，把当前产品范围收敛为三个静态图片模块：表情包、手机壁纸、电脑壁纸。

- 待实现：真实 Qwen 端到端验证、真实 Token/成本解析、审计日志、授权来源连接器和每日审核调度。
- 本轮新增：模板、候选审核和模型配置写入基础审计日志，提供 `/api/admin/audit-logs` 查询接口。
- 本轮新增：后台读写接口增加最小管理员角色门禁，Qwen 适配器解析供应商 usage 并写入 Token/成本台账。
- 本轮新增：模型配置支持删除自定义模型；内置模型和已有调用记录的模型只能停用，不能删除。
- 本轮新增：前台恢复参考图片上传与 Qwen `image` 参数；后台用量账单增加多维筛选。
- 本轮新增：后台来源连接器登记、授权状态、模式和启停配置，默认不启用未授权来源。
- 本轮新增：来源批量导入、批次号和重复指纹拦截，避免同一模板重复进入审核队列。
- 本轮新增：审核时间、审核原因和每日审核概览，支持按模块查看待审、发布和拒绝数量。
- 本轮新增：候选审核队列支持按状态、模块和批次筛选，并展示批次号和审核备注。
- 本轮新增：模板版本历史查看和安全回滚，回滚会生成新的版本号并保留旧快照。
- 本轮新增：模型配置页增加不计费的配置检查，可提示启用状态、远端模型 ID、接口地址和 Key 是否齐全。
- 本轮新增：前台增加“不希望出现”负面提示词，生成记录持久化该字段，真实 Qwen 调用发送 `negative_prompt`，Mock 回执标记是否已附加。
- 本轮新增：模型接口地址增加 `http(s)` 校验，拒绝把 API Key 当作地址保存；API Key 继续只从环境变量读取。
- 本轮新增：用户端模型选择改为读取后台启用配置，支持自定义生图模型；接口异常或没有可用模型时会明确禁用生成。
- 本轮新增：后台审核页增加审核快照，可按模块记录每日待审、发布和拒绝数量，并支持历史查询。
- 本轮新增：授权官方 API 连接器支持 JSON 模板同步；同步结果进入候选审核队列，复用批次和指纹去重，并记录审计日志。
- 本轮新增：后台总览和用量账单增加 Token 用量聚合展示，按现有筛选条件统计供应商返回的 Token。
- 本轮新增：候选模板保存提示词骨架，审核通过后继承到正式模板；人工导入页和官方 API 同步都支持该字段。
- 本轮新增：用量账单增加全部、今天、近 7 天时间范围；总览的“今日调用”改为按今天统计，避免把历史调用当成当日数据。
- 本轮新增：候选模板增加暴力/血腥、成人/裸露规则预检提示；仅提示审核员，不自动拒绝内容。
